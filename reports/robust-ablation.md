# 鲁棒增强消融结果

该报告只使用分组验证集及其合成压力子集；最终测试集仍然保留。
与基线相比，训练模型、数据划分、输入尺寸、优化器、seed 和训练预算保持一致，
实际生效的是 HSV 饱和度/亮度扰动；Ultralytics 检测训练链不读取 `erasing` 参数。

| 指标 | YOLO11n 基线 | 鲁棒增强 | 变化 |
|---|---:|---:|---:|
| Precision | 76.36% | 73.18% | -3.19% |
| Recall | 60.99% | 61.98% | +0.99% |
| mAP50 | 67.55% | 66.78% | -0.77% |
| mAP50-95 | 35.95% | 35.80% | -0.15% |
| GPU median latency | 8.272 ms | 8.253 ms | -0.019 ms |
| GPU throughput | 117.67 FPS | 119.72 FPS | +2.06 FPS |
