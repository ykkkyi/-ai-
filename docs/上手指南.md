# 棉卫士上手指南

目标：先用你自己的棉花数据完成去重、短训检查和 YOLOv8n 基线；之后再验证鲁棒训练与边缘部署。原始数据、训练权重和缓存都保留在本地，不提交到 GitHub。

## 1. 创建环境

当前开发机已验证 RTX 5060 Laptop、8GB 显存、PyTorch 2.14 + CUDA 13。CUDA 版本不匹配时，按 PyTorch 官网给当前驱动选版本。

```bash
cd cotton-doctor
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-cu130.txt
```

验证：

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
cotton-doctor --help
```

## 2. 生成数据检查和无精确重复划分

把数据解压到本地一个目录，参数用引号包住，避免空格/中文路径被拆开：

```bash
cotton-doctor audit "/path/to/棉花数据集" --output data/processed/audit
cotton-doctor prepare "/path/to/棉花数据集" --output data/splits/exact
```

WSL示例：

```bash
cotton-doctor prepare "/home/ykkkyi/yky/falcons/det_cotton_leaf_disease_yolo棉花病虫害数据集4280-1201-616 yolo8类" --output data/splits/exact
```

打开 `data/splits/exact/split-report.json` 检查每类数量，打开 `data/splits/exact/excluded-copies.csv` 看排除的副本。该命令不移动、覆盖或删除原图。检查近重复、同株连拍、类别名称、错框和漏标之后，才把该划分当作正式实验数据。

## 3. 用一轮做冒烟测试

在正式长训前，确认权重能下载、数据路径可读、GPU显存够用：

```bash
cotton-doctor train --data data/splits/exact/data.yaml --model yolov8n.pt --epochs 1 --imgsz 640 --batch 8 --device 0 --workers 4 --name smoke_yolov8n
```

冒烟测试只验证软件链路，不是可报告的模型结果。若显存不足，先将 `--batch` 改为4或2。

## 4. 正式基线

冒烟测试成功且数据划分通过人工复核后：

```bash
cotton-doctor train --data data/splits/exact/data.yaml --model yolov8n.pt --epochs 120 --imgsz 640 --batch 8 --device 0 --workers 4 --seed 42 --name E0_yolov8n_seed42
```

训练日志和权重保存在 `runs/E0_yolov8n_seed42/`，目录已被 Git 忽略，不会上传。保存当前代码版本和数据清单哈希，便于复现。

## 5. 验证后再测最终测试集

训练期间只用验证集查看曲线、逐类结果和漏检样例：

```bash
cotton-doctor evaluate runs/E0_yolov8n_seed42/weights/best.pt --data data/splits/exact/data.yaml --split val
```

模型、置信度/NMS阈值和部署设置冻结以后，才加 `--split test --allow-test` 做最终测试。测试结果不能再用来选配置。

## 6. 本地网页

当前网页版支持单张图片上传、标框图显示以及JSON/CSV/图片下载。放入你本地训练好的权重后启动：

```bash
mkdir -p weights
cp runs/E0_yolov8n_seed42/weights/best.pt weights/best.pt
uvicorn cotton_doctor.web:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。首版还没有视频、USB相机和TensorRT引擎支持；接下来按计划逐项实现并测试。
