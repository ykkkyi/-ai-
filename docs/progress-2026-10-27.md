# 2026-10-27 阶段记录

## 收尾状态

E4 目标感知遮挡训练、同协议压力集评估和冻结测试集评估均已完成。默认成品冻结为 YOLO11n；测试集只评估一次，详细结果见 [`reports/final-test-yolo11n.md`](../reports/final-test-yolo11n.md)。

## 类别平衡消融

针对 YOLO11n 基线中 Fusarium Wilt 召回率低的问题，新增 `balance-train` 命令。它在训练清单中把含 class 4 的图像各重复一次：训练条目从 3,801 增至 4,143，验证集 1,085 张和测试集 544 张完全不变，原图和标签不修改。

`E3_balanced_fusarium_yolo11n_seed42` 实际完成 114 轮后保存了可用的 `best.pt`。验证集结果如下：

| 指标 | YOLO11n 基线 | 类别平衡 | 变化 |
|---|---:|---:|---:|
| Precision | 76.36% | 73.51% | -2.85 个百分点 |
| Recall | 60.99% | 63.55% | +2.55 个百分点 |
| mAP50 | 67.55% | 66.67% | -0.88 个百分点 |
| mAP50-95 | 35.95% | 36.07% | +0.12 个百分点 |
| Fusarium Wilt AP50 | 21.75% | 25.64% | +3.90 个百分点 |
| Fusarium Wilt Recall | 17.79% | 27.03% | +9.24 个百分点 |

六个合成压力集没有显示遮挡收益，遮挡 mAP50 为 52.51%，与基线 52.68% 基本相同；暗光和强光分别下降 0.96 和 1.97 个百分点。模型文件仍约 5.262 MiB，网络结构没有改变。GPU 端到端速度在三次重复测量中波动明显，报告使用同协议重复的中位行；正式边缘设备结论仍需在目标硬件上实测。

当前判断：类别平衡适合作为“提高稀有病害召回”的候选配置，但不是整体最优模型。最终选择要根据比赛对总体 mAP、召回率和 Fusarium Wilt 权重的评分规则决定，不能只看单一类别。

详细结果见 [`reports/balanced-fusarium-ablation.md`](../reports/balanced-fusarium-ablation.md)。E3 保留为稀有病害召回优先时的候选配置。

## E4 目标感知遮挡

E4 实际完成 105 轮。相对 YOLO11n 基线，clean validation mAP50 从 67.55% 降至 66.06%，mAP50-95 从 35.95% 降至 35.34%，GPU 端到端中位延迟从 8.272 ms 增至 11.459 ms；遮挡压力集 mAP50 从 52.68% 提升至 53.08%。结论是保留实验与负结果，不作为默认部署模型。详细结果见 [`reports/occlusion-ablation.md`](../reports/occlusion-ablation.md)。

## 冻结测试集

YOLO11n 在 grouped-v2 测试集 544 张图、842 个标注框上得到 Precision 79.47%、Recall 64.68%、mAP50 69.69%、mAP50-95 39.07%。该结果只对应冻结配置和当前数据清单，不代表真实田间或目标边缘设备成绩。
